Crie um sistema web completo, moderno e extremamente profissional para convites e confirmação de presença (RSVP) para uma comemoração de aniversário de casamento.

NÃO crie um site genérico ou um simples formulário. Quero uma experiência premium, elegante, emocional e personalizada para cada convidado.

## OBJETIVO DO SISTEMA

O sistema será utilizado para convidar pessoas para uma comemoração de aniversário de casamento.

Cada convidado ou família deverá receber um LINK EXCLUSIVO E PERSONALIZADO.

Exemplo:

meusite.com/convite/joao-silva-x8k29

ou

meusite.com/c/ABC123XYZ

Quando a pessoa abrir o link, o sistema deve identificar automaticamente quem ela é e personalizar toda a experiência.

Exemplo:

"Olá, João e Maria! ❤️"

"É uma alegria ter vocês conosco para celebrar este momento tão especial."

O nome do convidado NÃO deve precisar ser digitado manualmente. Ele deve estar vinculado ao convite criado pelo administrador.
